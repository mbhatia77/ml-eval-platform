Tier 2 ML ensemble

DeBERTa + XGBoost scoring across the ten quality dimensions. Target latency is under 50ms once real models are loaded.

Status: ensemble weights and confidence math are real. Inference is stubbed — DeBERTa returns 75.0 and XGBoost returns 70.0 for every dimension, so confidence stays about 0.95 and Tier 3 never runs.

When it runs

After Tier 1 accepts the question. The engine then asks DecisionRouter.needs_escalation whether to call Tier 3.

Inputs and outputs

  • Input: EvaluationInput and FeatureVector
  • Output: Tier2Result with a quality score, confidence, dimension scores, and an explanation

Scoring

  • Semantic dimensions (correctness, groundedness, relevance, hallucination, completeness): DeBERTa 0.7 / XGBoost 0.3
  • Surface dimensions (the rest): DeBERTa 0.4 / XGBoost 0.6
  • Per-dimension confidence from score agreement: 1 − |deberta − xgboost| / 100
  • Overall quality score is a weighted average; correctness, groundedness, hallucination, and bias/safety weigh most

Config

  • MODEL_TIER2_MODEL_PATH — default models/deberta-v3-eval
  • MODEL_TIER2_XGBOOST_PATH — default models/xgboost-features
  • THRESHOLD_TIER3_CONFIDENCE_MIN / MAX — default 0.7 and 0.9
