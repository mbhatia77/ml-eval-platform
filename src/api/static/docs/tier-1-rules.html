Tier 1 rule engine

Deterministic checks that catch obvious quality failures without model inference. Target latency is under 10ms.

Status: fully implemented. Any rule failure returns REJECT immediately and skips Tier 2 and Tier 3.

When it runs

First step in EvaluationEngine.evaluate. If Tier1Result.is_rejected is true, the engine hardcodes confidence 0.95 and returns Decision.REJECT.

Inputs and outputs

  • Input: EvaluationInput and FeatureVector
  • Output: Tier1Result with per-dimension scores, a quality score, and an explanation

Checks

  • Format: question must end with ?; blocklist tokens such as TODO or placeholder
  • Length: question 15–500 characters; answer at least 5 characters
  • Verbatim copy: question text (minus ?) longer than 30 characters and present in the source
  • Safety: blocklist patterns that pair harm/weapon/illegal/hack language with how/instructions/steps

Config

No environment knobs. Length and blocklist constants live on Tier1RuleEngine. Downstream pass/reject cutoffs are THRESHOLD_* and apply only after Tier 1 passes.
