Evaluator models

The pipeline scores a question with cheap rules first, then an ML ensemble, then an LLM only when confidence is uncertain.

Tier 1

Rule-based checks. Immediate reject for obvious failures. Fully implemented.

Tier 2

DeBERTa + XGBoost ensemble. Weighting is real; inference is still stubbed.

Tier 3

LLM-as-judge for the 0.7–0.9 confidence band. Prompt and parse are real; the API call is canned.
