src/evaluation/tier3_llm.py

Tier 3 LLM judge

LLM-as-judge for cases where Tier 2 confidence is in the uncertain band. The engine blends scores 0.3 Tier 2 / 0.7 Tier 3.

Status: prompt construction and JSON parsing are implemented. The LLM API call returns canned JSON (overall score 65, confidence 0.82). Escalation is a middle band, not a floor — confidence below 0.7 goes straight to REVIEW without calling the LLM.

When it runs

Only when DecisionRouter.needs_escalation is true: THRESHOLD_TIER3_CONFIDENCE_MIN ≤ confidence < THRESHOLD_TIER3_CONFIDENCE_MAX (defaults 0.7 and 0.9). With stubbed Tier 2 confidence of 0.95, this path is currently unreachable.

Inputs and outputs

  • Input: EvaluationInput and the Tier2Result
  • Output: Tier3Result with overall score, confidence, dimension scores, and an explanation
  • The engine keeps the Tier 3 explanation and dimension scores, and takes max of the two confidences

Prompt

The judge receives the source (truncated to 3000 characters), the generated question, the expected answer, and Tier 2 dimension scores. It is asked for JSON with an overall score, confidence, ten dimension scores, an explanation, and a pass/review/reject recommendation.

Config

  • MODEL_TIER3_PROVIDER — default openai
  • MODEL_TIER3_MODEL — default gpt-4
  • MODEL_TIER3_MAX_TOKENS — default 1024
  • MODEL_TIER3_TEMPERATURE — default 0.1
  • THRESHOLD_TIER3_CONFIDENCE_MIN / MAX — default 0.7 / 0.9
